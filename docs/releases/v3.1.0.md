# Education Agent Skills v3.1.0 — 22 October 2026

This update keeps the library's 165 skills across 20 domains and makes them easier to install, inspect and reuse. It combines a portable Agent Skills download with targeted improvements to educational guidance, privacy boundaries, installation and MCP runtime correctness. Educator judgement and clearly labelled original practitioner methods remain central.

## What changed

- **Educational guidance:** 37 targeted revisions address learner checking and assistance, source fidelity, realistic workload, contextual support, privacy and safeguarding boundaries. Eight guides move optional worked examples to linked resources; two overlap the targeted revisions. That means 43 distinct canonical skills changed and 122 stayed unchanged, including all 108 initially marked keep. Skill IDs, paths and input/output interfaces remain stable.
- **Installation and portability:** canonical rich sources remain at `skills/<domain>/<skill-name>/`. The generated portable edition uses standard frontmatter while preserving the complete original metadata in `references/education.json`, the original body and local resources. Codex marketplace registration/install guidance is corrected, and 12 explicit-only skills carry matching Codex policies. Plugin manifests move to 2.2.0 so clients can recognize the update; installed caches still need refreshing.
- **MCP correctness and safety:** nonexecuting YAML parsing, literal single-pass input substitution, dependency updates, bounded validation and OAuth capability correction improve the retained runtime. Packaged stdio checks cover the build, and a nested-fence repair restores the Learning Target guide's full intended prompt. Local MCP still exposes 165 prompts and 157 tools.

## Public MCP retirement

The library-operated public MCP service is retiring with this release; public signup is no longer offered. The library continues through GitHub downloads, source plugins, manual prompts and local/self-hosted MCP. Existing remote-only users need a supported local route or their own authenticated endpoint; credentials and client settings do not transfer automatically. See [migration guidance](../HOSTED_MCP_ACCESS.md).

Local stdio needs no Vercel, token or email configuration. Self-hosters deliberately choose their own deployment and configure their own origin, authentication and email provider if used. The repository disables Git-triggered Vercel deployments. GitHub/local distribution needs no deployment; this note does not certify a live endpoint pause, credential revocation, provider deletion or zero infrastructure charges.
